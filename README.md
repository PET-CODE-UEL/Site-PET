# PET CODE - Website

A modern website for PET CODE (Programa de Educação Tutorial) showcasing three main areas: Computação, Design, and Ciência de Dados.

## 🚀 Tech Stack

- **React 19** - UI framework
- **TypeScript** - Type safety
- **Vite** - Fast build tool
- **Tailwind CSS** - Utility-first CSS framework
- **React Router** - Client-side routing
- **Bun** - Package manager and runtime

## 📁 Project Structure

```
src/
  ├── components/
  │   └── Navbar.tsx          # Navigation component
  ├── pages/
  │   ├── HomePage.tsx         # Main page with three circles
  │   ├── QuemSomosPage.tsx    # About us page
  │   ├── ProjetosPage.tsx     # Projects showcase
  │   ├── AcoesPage.tsx        # Actions and activities
  │   └── EventosPage.tsx      # Events calendar
  ├── assets/                  # Static assets
  ├── types/                   # TypeScript type definitions
  ├── App.tsx                  # Main app component
  ├── main.tsx                 # App entry point
  └── index.css                # Global styles
```

## 🛠️ Development

### Prerequisites
- Bun (recommended) or Node.js
- Modern browser

### Installation & Setup

```bash
# Install dependencies
bun install

# Start development server
bun run dev

# Build for production
bun run build

# Preview production build
bun run preview
```

### Available Scripts

- `bun run dev` - Start development server with hot reload
- `bun run build` - Build for production
- `bun run preview` - Preview production build locally
- `bun run lint` - Run ESLint
